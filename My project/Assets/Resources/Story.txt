# モノクロハート — ノベルパートの文章（仮の文章。自由に書きかえてよい）
#
# 書き方
#   [1-before]        … ステージ1 のパズルの前
#   [1-after]         … ステージ1 をクリアしたあと（★1〜2）
#   [1-after-good]    … ステージ1 を ★3 でクリアしたあと（無ければ [1-after] が使われる）
#   [end-miren] [end-aimai] [end-ketsui] … エンディング（未練／曖昧／決意）
#   名前：セリフ      … 「：」の前が話す人。シロ・クロ・人間さん は立ち絵が出る
#   名前の無い行      … 地の文
#   @背景 教室        … 場所の表示を変える（Assets/Resources/Images/bg_教室.png があればその絵）。「心」を含む名前だと暗くなる
#   @タイトル 文字    … 画面の真ん中に大きく文字を出す（\n で改行）
#   @本来の姿         … シロとクロの色を本来の姿に戻す（決意エンド用）
#   # で始まる行      … メモ（ゲームには出ない）

# ================= 1章 擬態 =================
[1-before]
@タイトル 1章\n擬態
@背景 教室
新学期。知らない顔ばかりの教室。
先生：じゃあ、端から順番に自己紹介していこうか。名前と、好きなものをひとつ。
前の席の子：サッカー部です！　好きなのは、えっと、焼肉！
教室が笑う。……次は自分の番だ。
人間さん：（好きなもの……本当は、ひとりで絵を描くのが好き。でも、それを言ったら変に思われるかな）
@背景 心の中
クロ：適当に「音楽」とか言っとけばいいって。みんなそう言ってるし。
シロ：……本当は違うだろ。まずは、ぐちゃぐちゃになった心を整えよう。
人間さん：……うん。

[1-after]
@背景 教室
人間さん：えっと……好きなものは、音楽です。
当たりさわりのない拍手。誰の記憶にも残らない、ちょうどいい答え。
クロ：ほら、無難が一番。
シロ：……。

[1-after-good]
@背景 教室
人間さん：好きなものは……絵を描くことです。まだ下手だけど。
一瞬の静けさのあと、後ろの席から小さな声がした。
サキ：……わたしも描く。今度、見せて。
シロ：ほら。言ってみるもんだろ。

[2-before]
@背景 教室
先生：文化祭の班を決めるぞ。4人ずつ、好きに組んでいい。
「好きに」という言葉ほど、こわいものはない。
ミナト：なあ、こっち入んない？　ちょうど一人足りなくてさ。
声をかけてくれたのは、クラスの中心にいるミナトのグループ。
人間さん：（ありがたい。でも、あのグループのノリについていけるかな……）
@背景 心の中
クロ：断る理由なんてないでしょ。一人になる方がこわいって。
シロ：上から不安が降ってくる。よけながら、少しずつ整えればいい。

[2-after]
@背景 教室
人間さん：うん、入る入る！
自分の声が、少しだけ高くなっていた。
ミナト：よっしゃ、決まり！

[2-after-good]
@背景 教室
人間さん：うん、入る。……あ、でも、ノリが悪かったらごめん。
ミナト：なんだそれ。別にいいって、そんなの。
少しだけ、肩の力が抜けた。

[3-before]
@背景 放課後の廊下
ミナト：今日の放課後さ、みんなでカラオケ行かね？
今日は、ずっと楽しみにしていた画集の発売日。
人間さん：（行きたくないわけじゃない。でも、今日は……）
ほかの二人：行く行く！　もちろん来るよね？
@背景 心の中
クロ：ここで断ったら、次から誘われなくなるかもよ？
シロ：敵がまとめて撃ってくる。すき間をよく見て。……答えも、よく見て。

[3-after]
@背景 カラオケ
結局、ついてきてしまった。
人間さん：（画集、明日でも買えるし。……たぶん）
マイクが回ってこないように、ずっとタンバリンを叩いていた。

[3-after-good]
@背景 放課後の廊下
人間さん：ごめん、今日はどうしても行きたい本屋があって。次は行く！
ミナト：マジか。じゃあ次は絶対な！
思っていたより、あっさりしていた。
シロ：言ってみたら、案外こんなもんだ。

# ================= 2章 同調 =================
[4-before]
@タイトル 2章\n同調
@背景 教室
ミナト：なあ、文化祭のポスター、お前が描いてくれない？　絵うまいんだろ？
人間さん：え、あ……
ほかの係の仕事も、まだ山ほど残っている。
人間さん：（断ったら、がっかりされる。でも、全部は無理だ）
@背景 心の中
クロ：「いいよ〜」って言っとけば丸く収まるって。
シロ：ひし形の弾に当たると、まわりのマスがひっくり返る。整えた形が崩れても、あわてるな。

[4-after]
@背景 自分の部屋
人間さん：いいよ、描くよ。
夜中の二時。ポスターの下書きは、まだ半分も終わっていない。
クロ：みんなに喜ばれるならいいじゃん？
シロ：……目の下、クマできてるぞ。

[4-after-good]
@背景 教室
人間さん：ポスターは描くよ。でも、そのかわり、受付の係は誰かに代わってほしい。
ミナト：あー、そっか。お前ばっか大変だもんな。オッケー。
自分の手で、負担の形を少しだけ変えられた。

[5-before]
@背景 自分の部屋
スマホが震える。グループLINEの通知が止まらない。
LINE：「てかサキってさ、ちょっと空気読めなくない？」
LINE：「わかる笑」「それな」
既読をつけてしまった。何か返さないと、変に思われる。
人間さん：（サキは、絵を見せてって言ってくれた子だ）
@背景 心の中
クロ：スタンプ一個でいいじゃん。それで終わる。
シロ：言葉の弾は大きいが、まっすぐにしか飛ばない。……逃げ道は、ある。

[5-after]
@背景 自分の部屋
笑っている犬のスタンプを、ひとつ押した。
画面の中で、会話はすぐに次の話題へ流れていった。
胸の奥に、小さな石が残った。

[5-after-good]
@背景 自分の部屋
人間さん：（スタンプを押しかけて、やめた）
LINE：「明日の小テストの範囲どこだっけ？」
話題を変える一言を送った。誰も、それ以上サキの話はしなかった。
シロ：小さいけど、ちゃんと自分で選んだな。

[6-before]
@背景 昼休みの教室
サキが席を外したとたん、また始まった。
ミナト：な、お前もそう思うだろ？
全員の目が、こっちを向く。
人間さん：（うなずけば、それで済む。うなずけば……）
@背景 心の中
クロ：うなずくだけ。ね、簡単でしょ？
シロ：悪口と反転攻撃が同時に来る。崩れたところから、ひとつずつ直していけ。

[6-after]
@背景 昼休みの教室
人間さん：……まあ、ちょっとわかるかも。
笑い声。戻ってきたサキと、目が合った気がした。
クロ：セーフセーフ。
シロ：……本当に？

[6-after-good]
@背景 昼休みの教室
人間さん：うーん、自分はよく知らないから、なんとも。
ミナト：……ふーん。ま、いいけど。
少し空気が冷えた。でも、心の中は不思議と静かだった。

# ================= 3章 揺らぎ =================
[7-before]
@タイトル 3章\n揺らぎ
@背景 文化祭
文化祭当日。教室も廊下も、人であふれている。
受付、呼び込み、買い出し。あちこちから名前を呼ばれる。
人間さん：（あっちもこっちも、全部に「いいよ」って言ってしまった）
@背景 心の中
クロ：人気者はつらいねえ。
シロ：盤面が4つの島に分かれた。島から島へは、大砲のマスから大砲の向きに進めば飛べる。

[7-after]
@背景 文化祭
走り回っているうちに、文化祭は終わっていた。
自分の描いたポスターの前で写真を撮る人たちを、遠くから見ていた。

[7-after-good]
@背景 文化祭
サキ：ポスター、描いたのあなたでしょ。すごくよかった。
人間さん：……ありがとう。
初めて、自分の描いたものを、自分のものだと言えた気がした。

[8-before]
@背景 教室
進路希望調査の紙が配られた。第一希望の欄が、真っ白なまま。
ミナト：オレ、とりあえずみんなと同じ大学でいいや。お前もそうするっしょ？
人間さん：（本当は、美術の学校が気になっている。でも……）
@背景 心の中
クロ：みんなと同じにしとけば、まちがいないって。
シロ：心が混乱すると盤面が広がる。広がった外側は、全部白に戻せ。……余計なものを、手放すんだ。

[8-after]
@背景 教室
第一希望の欄に、みんなと同じ大学の名前を書いた。
字が、少しだけふるえていた。

[8-after-good]
@背景 教室
第一希望の欄に、小さく「美術」と書いた。
消しゴムを持った手を、なんとか止めた。
シロ：書いたな。

[9-before]
@背景 リビング
母：進路の紙、見たわよ。……本気なの？
人間さん：……。
母：絵で食べていける人なんて、ほんの一握りでしょう。
父は黙ってテレビを見ている。時計の音がやけに大きい。
@背景 心の中
クロ：「冗談だよ」って笑えば、全部なかったことになるよ。
シロ：いちばん苦しい所だ。それでも、一つずつ。

[9-after]
@背景 リビング
人間さん：……冗談だよ。ちゃんと考える。
母：そう。よかった。
自分の部屋に戻って、描きかけのスケッチブックを、引き出しの奥にしまった。

[9-after-good]
@背景 リビング
人間さん：本気だよ。……すぐに分かってもらえなくても、ちゃんと説明したい。
母：……今度、描いたもの、見せなさい。
それが「いいよ」なのか、まだ分からない。でも、話は終わらなかった。

# ================= 4章 決意 =================
[10-before]

@背景 心の中
クロ：知らないふりしとこ？　それが一番傷つかないって。
シロ：島に分かれた盤面に、言葉の弾。……大砲で逃げることもできる。でも、逃げ続けることはできない。

[10-after]
@背景 美術室
人間さん：え、なんのこと？

[10-after-good]

サキ：……正直に言ってくれたの、あなただけだよ。
サキは少し笑って、隣のイスを引いた。

[11-before]
@背景 教室

責めるような、さみしそうな声だった。

@背景 心の中
クロ：謝って、また毎日一緒にいればいいじゃん。前みたいにさ。
シロ：迫ってくる弾の壁には、必ず1か所すき間がある。……ちょうどいい距離は、ある。

[11-after]
@背景 教室

ミナト：だよな！

[11-after-good]
@背景 教室

ミナト：……なんだよ、早く言えよ。じゃあ、金曜はカラオケな。
人間さん：うん。金曜はカラオケ。

[12-before]
@背景 校門
卒業式の日。桜はまだ少し早かった。
ミナトは地元に残る。サキは遠くの街へ行く。自分は――。
サキ：最後に、何か言っておきたいこと、ある？
言いたいことは、たくさんある。でも、どれも喉の奥でつかえてしまう。
@背景 心の中

シロ：全部が来る。でも、ここまで来た心なら整えられる。……いってらっしゃい。

[12-after]
@背景 校門

サキ：うん。あなたも。
背中が遠ざかっていく。言えなかった言葉が、胸の中で白と黒にゆれていた。

[12-after-good]
@背景 校門
人間さん：ありがとう。あの日、絵を見せてって言ってくれて、すごくうれしかった。
サキ：……今さら言う？　ずるいな。
二人で笑った。桜の枝の先に、小さなつぼみが見えた。

# ================= エンディング =================
[end-miren]
@背景 心の中
クロ：ほらね。合わせてれば、何も起きない。
シロ：……何も、起きなかったな。
人間さんは、本音を飲み込んだまま、春の道を歩いていく。
言えなかった言葉たちは、心の底で黒くかたまったままだった。
シロ：いつか、また整えに来よう。そのときは、もう少し余裕を持って。

[end-aimai]
@背景 心の中
クロ：ま、悪くはなかったんじゃない？
シロ：答えは出なかった。でも、ゆれていることは、ちゃんと分かった。
白と黒がまざったままの心で、人間さんは前へ進む。
はっきりしない。でも、もう目はそらさない。

[end-ketsui]
@背景 心の中
クロ：……あーあ。もう、こっちの出番は終わりかな。
シロ：いや。建前も、本音と同じくらい大事な、心の一部だ。
二匹の毛並みが、ゆっくりと色を変えていく。
@本来の姿
シロ：本音は、白。
クロ：建前は、黒。……やっと元に戻れた。
人間さん：ありがとう。どっちの声も、ちゃんと聞いて、自分の言葉で決めるよ。
白と黒が、ひとつのハートの中で、静かに並んでいた。
